# 基于对手价调整

在画板估价和回合系数算完之后，根据对手（以及己方）上一回合的出价，把本轮出价往更贴近实战的方向拉一拉，避免估得太高孤掌难鸣，或估得太低被对手轻松盖过。

相关背景见 [画板快照定价](./board_snapshot_pricing.md)。

---

## 什么时候会动、什么时候不动

- 可在配置里关掉；默认是开的。
- 第 1 回合没有可参考的历史，一般不改。
- 幽静别墅、沉船密封舱这类**隐秘拍卖图**单独一套逻辑（画面上只见名次，不见具体金币）。
- 其余地图看快照里对手上一回合出了多少。

---

## 普通地图（能看见对手出了多少钱）

先估一个「对手接下来可能出多少」：通常在上回合对手出价基础上略抬一点；若自己上回合出得比对手还高，就更多参考自己的出价。

再拿当前估价和这个「可能价」比：

| 情况 | 大致做法 |
|------|----------|
| 估价明显偏高 | 往中间压一压，别一个人抬太高 |
| 仍偏高 | 跟到对手可能出的价位附近 |
| 略高于对手上回合 | 在自己和对手之间折中，但别超过「可能价」 |
| 已经偏低 | 适度跟着对手可能价走，别太怂 |

**最后一两轮**会更激进一点，防止临近结束时被秒。

**爱莎**还多两条：

- 对手已经出得离谱、超过本轮上限思路时，第 3 回合起不再跟着抬。
- 第 3 回合若前两轮自己领先、场面偏稳，会少跟对手的乱抬价；局面混沌时则仍按上表跟价。

**艾哈迈德**规则更简单：没有第 3 回合保护，也没有「对手过高就不跟」；终局是在当前价上加一点随机浮动，其余分支与爱莎类似但更粗。

---

## 隐秘拍卖图（只见名次）

上回合自己出了多少、排在第几名，用来猜对手本回合大概会出到什么水平（名次越靠后，猜得越高）。

然后和普通图类似：估高了就压、略高就折中、已经偏低就跟一点；最后几轮再抬一档。

第 1、2 回合信息不够，通常不调整。

---

## 在整条出价里的位置

画板算价 → 角色与回合处理 → **对手价调整** → 封顶与尾数等后处理 → 最终出价。
