# bidking-booooot 数据版本更新手册

游戏客户端或配置表仓库更新后，按本手册刷新 `data/` 下与定价、掉落权重相关的静态资源。

**工作目录**：`<repo_root>`（下文命令均在此目录执行）

**真相源**（可选）：从 [bidking-tool](https://github.com) 导出带表头 CSV，或直接在 `data/` 维护 CSV。
---

## 一、文件清单

### 1. 输入（bidking-tool 导出 CSV）

| CSV | 说明 |
|-----|------|
| `Item.csv` | 物品主表 |
| `Drop.csv` | 掉落图（`items_list` 列） |
| `RankMap.csv` | 地图排位 / 子图配置 |
| `Skill.csv` | 技能表（技能有变动时） |
| `Language.csv` | 可选；`col_1` 为空时解析 `item_name` 键 |

**导出命令**（在 bidking-tool 目录，可选）：

```cmd
cd /d <bidking-tool>
pip install -e ".[dev]"
wiki-build tables-to-csv --tables-dir <tables> --output-dir out\csv
```
或一键脚本：

```cmd
D:\workzone\bidking-tool\scripts\tables_to_csv.bat D:\workzone\bidking-resource\tables D:\workzone\bidking-tool\out\csv
```

可将所需 CSV 复制到 `data\`，或后续命令直接指向 `bidking-tool\out\csv`：

```cmd
copy /Y D:\workzone\bidking-tool\out\csv\Item.csv data\
copy /Y D:\workzone\bidking-tool\out\csv\Drop.csv data\
copy /Y D:\workzone\bidking-tool\out\csv\RankMap.csv data\
copy /Y D:\workzone\bidking-tool\out\csv\Skill.csv data\
copy /Y D:\workzone\bidking-tool\out\csv\Language.csv data\
```

### 2. 工具生成（跑命令产出）

| 输出文件 | 生成命令 |
|----------|----------|
| `item_prices.csv` | `bidking-item-table` |
| `drop_table_weights.csv` | `bidking-game-tables` |
| `rank_map_export.csv` | `bidking-game-tables` |
| `calculator_data_merged.csv`（DROP 行） | `bidking-game-tables --data-dir data --merge-calculator data\calculator_data_merged.csv --merge-out data\calculator_data_merged.csv` |
| `Skill_export.csv` | `bidking-skill-table` |
| `map_quality_avg_out.csv` | `python tools\map_quality_avg_prices.py` |
| `map_quality_p25_out.csv` / `map_quality_p50_out.csv` | `python tools\map_quality_p25_p50_prices.py` |
| `物品轮廓爆率推断器.html`（`NEST_W` / `SUBMAP_PRIOR_MULT`） | `python tools\update_infer_html_embed.py` |

### 3. 可选 / 手工维护

| 文件 | 说明 |
|------|------|
| `物品轮廓爆率推断器.html`（`EMBED_CSV.rate` 等） | 爆率表若独立变更需手工；`--sync-embed-item` 可同步物品内嵌 CSV |

### 4. 无需随版本重生成

| 文件 | 说明 |
|------|------|
| `self_bid_cache.json` | 运行期出价缓存（本地，已 gitignore） |

## 三、完整更新流程（推荐）

### 步骤 0：导出最新 CSV（bidking-tool）

见上文「输入」一节的 `wiki-build tables-to-csv` 命令。

### 步骤 1：物品价格表

默认读取 `data\Item.csv`：

```cmd
bidking-item-table --out data\item_prices.csv
```

直接引用 tool 输出目录时：

```cmd
bidking-item-table --item-csv D:\workzone\bidking-tool\out\csv\Item.csv --lang-csv D:\workzone\bidking-tool\out\csv\Language.csv --out data\item_prices.csv
```

导出规则：`item_id > 1_000_000`，且 `category_tags` 含 101–110（棋盘藏品）、14（皮肤）或 100（特殊档）。

### 步骤 2：掉落与地图表

默认读取 `data\Drop.csv`、`data\RankMap.csv`：

```cmd
bidking-game-tables --data-dir data --merge-calculator data\calculator_data_merged.csv --merge-out data\calculator_data_merged.csv
```

直接引用 tool 输出目录时：

```cmd
bidking-game-tables --data-dir D:\workzone\bidking-tool\out\csv --drop-csv data\drop_table_weights.csv --rank-csv data\rank_map_export.csv --merge-calculator data\calculator_data_merged.csv --merge-out data\calculator_data_merged.csv
```

产出：

- `drop_table_weights.csv`
- `rank_map_export.csv`
- （可选）原地更新 `calculator_data_merged.csv` 的 DROP 行

### 步骤 3：技能表（技能有变动时）

```cmd
bidking-skill-table --out data\Skill_export.csv
```

或：

```cmd
bidking-skill-table --skill-csv D:\workzone\bidking-tool\out\csv\Skill.csv --out data\Skill_export.csv
```

若本机有 `build\` 脚本，继续：

```cmd
python build\generate_skill_export_table.py
python build\generate_skill_parsing_report.py
```

技能语义变化时还需人工检查 `src\bidking\parsing\skill_bindings.py`。

### 步骤 4：推断器 HTML 巢权重 / 子图池化（影响 bot 定价先验）

在 **`item_prices.csv` 与 `calculator_data_merged.csv`（DROP）已更新后** 执行：

```cmd
python tools\update_infer_html_embed.py
```

可选：同时把 `item_prices.csv` 写入 HTML 内嵌 `EMBED_CSV.item`：

```cmd
python tools\update_infer_html_embed.py --sync-embed-item
```

预览不重写文件：

```cmd
python tools\update_infer_html_embed.py --dry-run
```

**含义简述**

| 常量 | 算法 |
|------|------|
| `NEST_W[nest]` | 巢穴根 `drop_id` 池在品质 1–6 下的条件期望件均价 |
| `SUBMAP_PRIOR_MULT[tier][map][item]` | 该子图池内物品份额 ÷ 同档基础子图（如 2101–2107）均值 |

二者由 `item_db._resolve_drop_to_items` 从 `calculator_data_merged.csv` 展开；bot 启动时从 HTML 读入（`item_db.load_map_prior_data`）。

若新增子图且不在 `item_db.MAP_TO_TIER_NEST` / HTML `SUBMAPS_BY_TIER` 中，需先改代码再重跑本脚本。

### 步骤 5：地图品质均价 / 分位价

依赖：`item_prices.csv`、`calculator_data_merged.csv`；巢权重已写入 HTML 时 bot 定价与推断器一致。

```cmd
python tools\map_quality_avg_prices.py
python tools\map_quality_p25_p50_prices.py
```

`map_quality_avg_prices.py` 默认写入 `data\map_quality_avg_out.csv`；仅预览可加 `--no-write`。

### 步骤 6：校验

```cmd
python -m pytest tests/parsing/test_item_db_maps.py tests/parsing/test_skill_csv_registry_consistency.py tests/tools/test_item_table.py tests/tools/test_game_tables.py tests/tools/test_skill_table.py -q
```

关注：

- RankMap 新 `map_id` 是否已在 `src\bidking\parsing\item_db.py` 的 `MAP_TO_TIER_NEST` 中登记
- 技能 CSV 与 `skill_bindings` 是否一致

## 四、最小更新（仅 Drop / RankMap 变动）

未新增物品、未改技能时：

```cmd
bidking-game-tables --data-dir D:\workzone\bidking-tool\out\csv --merge-calculator data\calculator_data_merged.csv --merge-out data\calculator_data_merged.csv
python tools\map_quality_avg_prices.py
python tools\map_quality_p25_p50_prices.py
```

（若 CSV 已复制到 `data\`，将 `--data-dir` 改为 `data` 即可。）

## 五、可能需要改代码的情况

| 现象 | 处理 |
|------|------|
| `test_item_db_maps` 报 RankMap id 缺失 | 在 `item_db.py` 的 `MAP_TO_TIER_NEST` 补充新地图 → 巢穴映射 |
| 新地图档定价参数 | 检查 / 新增 `configs\pricing.maps\*.json` |
| 新技能 id / 日志字段 | 更新 `Skill_export.csv` 后跑 build 脚本，并改 `skill_bindings.py` |
| 子图池化 / 巢权重变化 | `python tools\update_infer_html_embed.py`（见步骤 4） |

## 六、CLI 速查

| 命令 | 作用 |
|------|------|
| `wiki-build tables-to-csv`（bidking-tool） | `tables/*.txt` → `out/csv/*.csv` |
| `bidking-item-table` | `Item.csv` → `item_prices.csv` |
| `bidking-game-tables` | `Drop.csv` / `RankMap.csv` → 派生 CSV |
| `bidking-skill-table` | `Skill.csv` → `Skill_export.csv` |
| `python tools\update_infer_html_embed.py` | 重算 HTML 内 `NEST_W`、`SUBMAP_PRIOR_MULT` |

**常用参数**

| 命令 | 参数 | 默认 |
|------|------|------|
| `bidking-item-table` | `--item-csv` / `--lang-csv` / `--out` | `data/Item.csv`、`data/item_prices.csv` |
| `bidking-game-tables` | `--data-dir` / `--drop-csv-in` / `--rank-csv-in` | `data/` 下 `Drop.csv`、`RankMap.csv` |
| `bidking-skill-table` | `--skill-csv` / `--out` | `data/Skill.csv`、`data/Skill_export.csv` |

## 七、依赖关系简图

```
bidking-resource/tables/*.txt
        │
        ▼  wiki-build tables-to-csv（bidking-tool）
out/csv/Item.csv ──────────────► item_prices.csv ──┐
out/csv/Language.csv（可选）                        │
                                                    ├──► map_quality_*_out.csv
out/csv/Drop.csv ──┬──► drop_table_weights.csv ───┤
                   └──► calculator_data_merged.csv ┘
out/csv/RankMap.csv ─────► rank_map_export.csv
out/csv/Skill.csv ───────► Skill_export.csv ──► skill_export_generated.py（本地 build）

update_infer_html_embed.py ──► 物品轮廓爆率推断器.html（NEST_W / SUBMAP_PRIOR_MULT）
                                      └──► item_db 巢权重 / 子图先验（bot 定价）
```
